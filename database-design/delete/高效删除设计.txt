TODO. 如何快速删除DB中千万行以上的数据 ?
约束条件:
- Table表必须保证可用性, 删除期间必须支持Insert
- Table表结构不能修改, 无法创建临时表或分区
- Table表中数据必须根据条件删除, 无法直接Truncate

实现思路:
1. 分析表结构和表关联，确定删除条件和Index索引等信息
2. 分析DELETE语句的执行计划
3. 确定最高效的SQL(避免大表JOIN)
4，执行并行 + 分批DELETE + COMMIT模式删除

实现细节: 划分批次和切分数据(取模或判断范围)
DELETE FROM Table WHERE ROWID IN (
 SELECT ROWID FROM Table
 WHERE column = value AND
 MOD(ID, :parallelCount) = :parallelIndex
 AND ROWNUM <= :batchSize)
