TODO. 如何快速删除DB中千万行以上的数据 ?
约束条件:
- Table表必须保证可用性，删除期间必须支持数据插入
- 表结构不能修改，不能创建临时表，无法CTAS重建表，不能PARTITION分区表
- 必须根据条件删除数据，无法直接Truncate整个表

核心难点:
- 大数据导致提交和回滚困难
- 表直接的外键关联会导致连带删除: 删除record标识删除所有外键指向它的数据

设计实现:
1. 分析表结构和Index索引等信息，分析DELETE语句执行计划
2. 直接在原表删除，避免大表JOIN
3. 表中大字段(content)索引是性能杀手(删除每行=更新Index树)
4. 根据ID切片数据 MOD(ID, :parallelCount) = :parallelIndex
5. 循环模式: 并行删除+分批提交，限制每批事务大小
   while (true) {
     int deleted = deleteBatch();
     if (deleted == 0) break;
   }
